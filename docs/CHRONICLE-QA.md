# 조선의 삶 확장 QA

검토일: 2026-11-03.

## 자연 진행으로 확인한 도달성

`node scripts/chronicle-audit.cjs 10`으로 **12개 목표 × 시드 1–10 = 120판**을 진행했다. 매 판은 같은 본관 인덱스 0, 상민 배경의 1392년 시작 상태에서 출발했다. 준비·완수·계승 등 공개 게임 함수를 사용했고, 연도·가족·능력치·난수 상태·완료 플래그는 수정하지 않았다.

정책은 목표 하나를 선택하고, 화면에 표시되는 자원·능력 조건을 채우는 선택을 우선한다. 완수 뒤에도 가족의 생계를 관리하면서 실제 종료까지 진행한다. 잠긴 선택은 건너뛰고 준비를 보류하며, 계승에는 엔진이 정렬한 첫 후보를 택한다. 이는 사람이 플레이하기 쉽다는 측정이나 최적 전략을 뜻하지 않는다.

12개 결과 모두 실제 준비·완수를 거쳐 대표 결말까지 최소 한 번 도달했다. 나머지 28판의 대표 결말은 계보 단절이었다. 도달하지 못한 결과를 임의로 부여하거나, 가족이 단절된 판을 성공으로 집계하지 않았다.

진행 함수 호출 후 **20,555회** 계보 검증과 JSON 저장·복원 검증을 수행했고 오류가 없었다. 이 수에는 결과 확인·방향 설정·대표 계승도 포함되므로 20,555턴을 플레이했다는 뜻은 아니다. 조선 이야기 상태가 저장 복원 과정에서 달라지지 않는지도 확인했다.

이 표는 실행에서 관찰한 집계다. 원래의 개별 실행 JSON은 Playwright가 `test-results`를 정리하면서 삭제되었으므로 이 문서에서 개별 실행 기록을 재구성하지 않는다. 향후 실행의 출력 경로는 `docs/chronicle-audit-results.json`으로 바꿨다.

## 브라우저 검증 범위

새 `e2e/chronicles.spec.ts`는 데스크톱과 모바일에서 다음을 검사한다. 기존 계보·신분·과업 테스트는 별도로 유지한다.

- 조선의 삶 6개 카드, 시대별 잠금, 실제 선택에 의한 준비와 완수, 결과 표시와 새로고침 후 보존.
- 자연 진행 중 교육 조건을 충족하지 못한 선택의 비활성화, 엔진의 선택 거부, 보류 뒤 준비 상태 유지.
- 26개 결말 도감, 분류 필터, 발견한 결말 필터.
- 실제 시작부터 자연 종료한 구휼 가문의 결말 수집, 새로고침 중복 방지, 같은 시드 재도전의 진행 초기화와 수집 기록 유지.
- 실제 진행으로 도달한 1894년 이후의 새 조선 이야기 폐쇄, 과거 성취 보존.
- 가로 넘침과 페이지 오류 확인, 패널·선택 결과·도감 스크린샷 생성.

이 문서는 최종 브라우저 실행 결과를 미리 주장하지 않는다. 최종 통과 여부는 해당 변경 이후의 Playwright 실행 결과를 기준으로 한다.

## 해석의 한계

시드 10개, 시작 배경 하나, 특정 휴리스틱 정책의 결과다. 모든 출발 배경과 모든 선택 조합에 대한 증명이 아니며, 실제 이용자의 이해도·몰입도·재방문률을 측정하지 않았다. 26개 전체 결말 중 이번 감사의 자연 도달성 대상은 새 생활사 결과 12개다. 다른 결말의 자연 도달성을 이 결과로 대신 주장하지 않는다.
