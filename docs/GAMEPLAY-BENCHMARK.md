# 천년가문 게임성 벤치마크

검토일: 2026-11-03. 유명 웹게임의 실제 구조와 제작자 자료를 참고했다. 아래의 기능은 확인 가능한 사실이지만, 그 기능이 흥행의 원인이라는 설명과 천년가문에도 효과가 있을 것이라는 판단은 설계 가설이다. 게임별 이용자 수나 천년가문의 유지율을 측정한 결과가 아니다.

Cookie Clicker의 개발사 소개는 Steam판의 설명이다. 이 자료로 업그레이드 구조를 참고했으며, Steam 평가 수를 웹판의 이용자 규모나 인과적 성공 근거로 사용하지 않았다. 다른 게임의 문구·미술·코드를 복제하는 대신 천년가문의 가족·세대 맥락에 맞게 적용한다.

## 이번 개선의 설계

- **가문 과업 3종:** 배움·상업·돌봄 중 한 경로에 맞는 선택을 3회 쌓고 해당 능력 조건을 충족한다. 진행도와 조건을 보여 주며, 달성 시 즉시 보상과 특별 선택지를 제공한다. 특정 수치만 반복해서 올리는 행동에 목표와 결과를 연결하려는 설계다.
- **잠긴 특별 선택지:** 획득한 가문 유산이 실제 사건의 대응 범위를 넓힌다. 잠긴 이유를 표시해 다음에 무엇을 준비해야 할지 알 수 있게 한다.
- **상황에 맞는 사건:** 가족과 자원의 현재 상태를 사건 선택에 반영한다. 같은 생활 사건이 맥락 없이 반복되는 느낌을 줄이는 것이 목적이다.
- **초반 피드백 단축:** 첫 3턴은 5년씩 진행한다. 한 번의 선택으로 오랜 세월이 지나가기 전에 가족과 선택 결과를 익히게 한다.
- **기록과 재도전:** 브라우저 안에 최고 기록을 보존하고 같은 시드로 다시 시작할 수 있게 한다. 다른 선택을 시험할 기준을 제공한다. 공개 순위표나 서버 기록은 아니다.

성씨·본관 자체에는 능력 보너스를 부여하지 않는다. 가문의 특색은 플레이 중 선택으로 형성한다. 확률적 생사와 긴 역사 진행을 유지하면서 플레이어가 통제할 수 있는 목표와 보상을 더하는 방향이다.

## 이후 평가할 항목

현재 참여도 분석이나 외부 전송용 텔레메트리는 구현하지 않았다. 브라우저 최고 기록은 개인의 플레이 기록이며, 아래 지표를 측정하는 분석 시스템이 아니다. 따라서 이번 변경으로 재미·유지율이 개선되었다고 단정하지 않는다.

| 후보 지표 | 확인할 질문 |
| --- | --- |
| 첫 3회 선택 완료 비율 | 목표와 선택 방법을 빠르게 이해하는가? |
| 첫 과업 달성 비율·소요 선택 수 | 보상이 너무 멀거나 자동으로 달성되지는 않는가? |
| 과업별 선택·완료 분포 | 한 경로가 다른 경로보다 지나치게 유리하지 않은가? |
| 첫 계승 도달 비율 | 초반이 납득할 만한 난도인가? |
| 엔딩 후 재시작·동일 시드 재도전 비율 | 다른 전략을 시험할 이유가 생겼는가? |
| 플레이테스트의 실패 이유 설명 | 플레이어가 단절 이유와 다음 판에서 바꿀 행동을 말할 수 있는가? |

우선 실제 플레이 관찰과 인터뷰로 이해도·반복감·선택의 차이를 확인한다. 나중에 분석을 도입한다면 수집 범위와 개인정보 처리 방식을 별도로 정하고, 변경 전후를 비교할 수 있는 기준을 마련한다.
