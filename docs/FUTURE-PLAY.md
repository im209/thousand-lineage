# 현재를 지나 이어가는 가문

- 2026년은 최종 연도 대신 생존 결말을 수집하는 중간 기록이다. 결말 화면의 ‘이 가문으로 미래까지 이어가기’에서 같은 가족·자원·신분·유산을 보존하고 계속한다.
- 기존 version 1의 2026년 생존 저장에서도 버튼을 제공한다. 후손이 없는 단절은 계속할 수 없다. 대표만 사망하고 후손이 남은 경우에는 후계자 선택으로 이어진다.
- 계속하기는 선택한 저장에 `endless: true`를 추가한다. 이후에는 연도에 의한 종료가 없으며, 계승 가능한 후손이 사라질 때 끝난다. 2026년 이후는 ‘가상의 미래’로 표시하고 기존의 일반 생활·교육·생업 사건을 사용한다. 미래의 실제 사건이나 기술을 예측하는 콘텐츠는 아니다.
- 2026년 결말과 수집 도감은 보존한다. 미래 구간은 별도 기록 ID로 저장하므로 이후 단절 결과가 이전 생존 결말을 덮어쓰지 않는다.
- 저장·최고 기록·공유 링크에서 634년 및 100세대 제한을 제거했다. 잘못된 숫자·음수·안전한 정수 범위 밖 값은 계속 거부한다. 출발 조건 비교용 규칙 버전은 `family-20261106-3`이다.

검증: `future.test.ts`에서 기존 저장 재개, 4000년 이후 진행, 150세대 기록·공유, 단절·계승, 기존 결말 보존을 검사한다. `e2e/future.spec.ts`에서 PC·모바일의 실제 계속하기와 재접속 복원을 검사한다.
