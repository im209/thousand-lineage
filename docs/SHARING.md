# 도전과 공유

## 사용 흐름

결과 화면에서 ‘친구에게 도전 보내기’를 누르면 지원 기기의 공유창이 열린다. 미지원이거나 전송 호출이 실패하면 텍스트·링크 복사로 전환한다. 복사 권한도 없으면 직접 선택 가능한 텍스트를 제공한다. 사용자가 공유를 취소한 경우 복사나 다운로드를 자동 실행하지 않는다.

이미지 바로 공유는 PNG 파일 공유를 지원하는 기기에서 사용할 수 있다. 미지원이면 이미지 저장과 링크 공유를 안내한다. 특정 앱의 설치나 실제 전송까지 보장하지 않으며, 카카오톡 전용 SDK를 별도로 등록한 것은 아니다. 휴대폰의 공유 대상은 설치 앱과 OS·브라우저에 따라 다르다.

랜덤 가문은 공개된 성씨·본관 조합 중 균등 추첨한다. 실제 인구 비율을 재현하지 않는다. 선택 결과는 검색 화면에서 먼저 확인하고, 시작 버튼과 창시자 확인을 거쳐 게임에 들어간다.

## 링크 데이터

- 사이트 경로의 `#challenge=...`에 버전, 규칙 식별자, 시드, 본관 ID, 출발 신분, 생존 연수, 계보 세대만 담는다.
- 전체 저장·개인 설정·인물 명단·결말 ID·결말 이름을 링크에 넣지 않는다. 점수는 공유자가 제공한 요약이며 서버 검증 순위표가 아니다.
- 길이와 인코딩, 정수 범위, 본관·신분, 규칙 버전을 검증한다. 잘못된 링크는 기존 기록에 손대지 않고 안내한다.
- 이전 규칙의 기록은 읽을 수 있지만 같은 조건의 새 게임 시작은 막는다. 출발이나 시뮬레이션 규칙 변경 시 `CHALLENGE_RULES`를 갱신한다.
- 링크를 받으면 친구 기록·가문·출발 신분·첫 인물을 보여준다. 명시적인 시작 버튼을 누르기 전에는 기존 자동 저장을 교체하지 않는다.
- 수락 시 세대·기간의 비교 목표를 새 게임에 보존한다. 도전 중 새로고침, 종료 뒤 같은 운명 재도전에도 비교 목표는 남는다.

## 공유 이미지와 아바타

공개 링크 미리보기는 `public/share-card.png`의 일반 게임 카드다. 정적 GitHub Pages에서는 링크마다 친구 점수가 들어간 서버 렌더링 OG 카드를 만들지 않는다. 친구의 실제 기록은 메시지 텍스트와 링크 수신 화면, 직접 공유하는 PNG에서 확인한다.

아바타는 DiceBear Pixel Art(CC0)를 로컬에서 생성한다. 출처와 고지는 [AVATAR-SOURCES.md](AVATAR-SOURCES.md)에 있다. 인물 이름·ID 등으로 만든 별도 시드만 사용하며 게임 난수와 현재 직업·나이는 얼굴 생성에 쓰지 않는다.

## 검증

- 링크 경계값, 손상·중복·이전 버전, 4개 신분의 전달을 단위 테스트한다.
- 링크 열기 전후 자동 저장, 수락 후 동일 출발 조건, 도전 목표의 새로고침·재도전 보존을 실제 브라우저에서 검사한다.
- 네이티브 공유 API와 복사 API를 대역으로 검사한다. PNG는 실제 Canvas로 생성하고 이미지 크기·형식을 확인한다. 특정 앱으로 실제 메시지를 보내지는 않는다.
- 가족의 성씨 규칙과 별도로, 어머니가 남성으로 오인되지 않게 성별·부모 역할 표시를 확인한다.
