# 도메인과 호스팅

현재 게임: https://thousand-lineage.kklee09.chatgpt.site

GitHub Pages 목표: https://im209.github.io/thousand-lineage/

사용자는 `1000gamun.com`을 후보로 골랐으나 도메인 구매는 나중에 하기로 했다. 구매·결제·DNS 변경은 진행하지 않는다. 이전 조회 결과와 가격은 구매 전에 다시 확인해야 한다.

이 공개 저장소에는 계정별 도메인 검증 토큰이나 DNS 소유권 인증값을 보관하지 않는다. 실제 도메인을 구매하면 사용할 호스트를 고르고 해당 호스팅 서비스의 최신 안내에 따라 도메인과 DNS를 연결한다.
