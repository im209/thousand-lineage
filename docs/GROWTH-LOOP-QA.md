# 성장 흐름 수정 · 2026-11-06

사용자 피드백은 ‘처음에 무엇을 할지 모르겠다’, ‘스탯의 혜택이 보이지 않는다’, ‘선택만 하다 끝난다’였다. Claude Code의 독립적인 코드·스크린샷 리뷰 뒤 주요 원인을 엔진 실행으로 재현했다. 기존 E2E 통과는 초보자의 이해나 재미를 증명하지 않는다.

## 수정

- 새 게임은 생업·가족 방향으로 시작한다. 첫 생활 선택 뒤 신분 사건에 자동 진입하지 않는다. 기존 저장된 진로는 변경하지 않으며, 신분 진로의 생업 복귀 선택은 실제로 가족 방향으로 돌린다.
- 학업·기술 수련은 배움 과업의 관련 선택으로 계산한다. 선택 직후와 연간 가족 생활을 마친 뒤 완성 조건을 확인하되, 한 번의 선택을 두 번 계산하거나 보상을 중복 지급하지 않는다.
- 추천 목표 하나, 현재 목표의 진행·능력 조건·실제 보상을 이야기 화면에서 확인한다. 관련 선택에는 진행 표시가 붙는다.
- 기존 연결 60 혜택(큰 거래 비용 재산 8→3)을 미리 안내하고 조건을 넘긴 결과에서 알린다. 여덟 지표의 실제 쓰임을 펼쳐서 확인한다. 영향력 점수만으로 신분·관직이 바뀐다고 설명하지 않는다.
- 선택 결과 문장은 실행한 행동을 설명한다. 출생·혼인·사망 같은 확률 사건은 별도 ‘그동안 가족에게는’ 아래에 표시해 선택이 직접 출생을 보장한 것처럼 묘사하지 않는다.
- 창시자 이름·신분·첫 시작 버튼을 먼저 보여주고 상세 지표를 접었다. 현재 대표 이름과 나이·생업은 초기 안내 종료 후에도 이야기 화면에 남는다.

## 검증 기준

- 신분 네 종류와 여러 시드에서 기본 경로가 가족 생활인지, 첫 세 선택이 5년 단위인지 확인한다. 생존·계승으로 조기 종료되는 규칙은 유지한다.
- 기본 진로를 픽스처에서 바꾸지 않는 실제 새 게임 E2E로 첫 세 선택을 검사한다.
- 기존 신분 진로 저장을 복원할 수 있고, 명시적인 생업 복귀가 반복 경로를 끝내는지 확인한다.
- 학업 선택의 과업 진행 1회 증가·저장 복원·중복 클릭 방지를 확인한다.
- 연결 60 안내와 실제 거래 비용이 일치하는지, 이미 충족한 혜택을 매 선택마다 다시 알리지 않는지 확인한다.
- 연간 혼인으로 남은 인맥 조건이 충족돼도 과업을 즉시 1회 완성한다.
- 구형 결과에 `outcome`이 없어도 읽으며 잘못된 타입의 새 필드는 거부한다.
- PC와 모바일에서 시작 버튼·첫 선택이 실제 뷰포트에 들어오는지, 결말 비밀·계승·백업·재도전 회귀를 확인한다.

## 남은 제품 검증

실제 초보자 관찰로 첫 선택까지의 시간, 3턴 뒤 목표 이해, 창시자 이름 기억, 반복 플레이 의도를 확인해야 한다. 이번 수정은 사용성·규칙 연결의 개선이며 재미 향상이 측정됐다고 주장하지 않는다. 혼인 상대 선택, 작명, 추모 장면은 이번 범위에 포함하지 않는다.
