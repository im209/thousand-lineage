# 한복 도트 캐릭터

천년가문 전용으로 작성한 자체 SVG 도트 캐릭터다. 카이로소프트의 작은 캐릭터에서 느껴지는 친근한 비율을 참고하되, 해당 게임의 이미지나 스프라이트를 가져오지 않았다.

- 원본: src/portrait-art.mjs. 48×48 격자에 둥근 얼굴, 작은 점눈, 볼터치, 파스텔 한복, 상투·묶음머리를 직접 그린다.
- 머리 모양·저고리·리본·배경색은 인물 ID·본관·출생연도·이름·성별로 만든 별도 시드에서 정한다. 게임 난수와 현재 나이·직업은 사용하지 않는다.
- 외부 이미지 서버와 아바타 패키지에 의존하지 않는다. 그림만으로 성별이나 부모 역할을 추정하지 않도록 기존 성별·아버지·어머니 라벨도 유지한다.
- node scripts/generate-share-card.mjs로 같은 원본에서 공유용 SVG·PNG를 생성한다. 기존 Playwright Chromium 설치가 필요하다. 개인 결과 PNG 역시 같은 캐릭터를 사용하고 결말 이름은 포함하지 않는다.

기존 DiceBear 초상과 관련 패키지는 교체되어 현재 사용하지 않는다.
