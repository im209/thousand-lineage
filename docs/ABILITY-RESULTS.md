# 능력 판정과 결과 연출

2026-11-13. 사용자가 요청한 ‘능력치로 사건을 해결하는 느낌’과 선택 뒤 결과 애니메이션을 과거길·과거시험부터 적용했다.

- 과거시험은 기존 공식(기본 8% + 개인 교육 × 0.4%p + 개인 능력 × 0.2%p + 가문 교육 × 0.2%p, 최저 8%·최고 80%)을 유지한다. 판정 시점의 인물 ID와 세 능력치, 실제 성공 확률 및 결과를 저장한다.
- 과거길 강행은 사건·성격에 따른 기존 위험도에서 능력 50, 건강 50을 기준으로 보정한다. 능력 1점당 사망 위험 0.2%p, 건강 1점당 0.1%p를 낮추며 50점 미만은 반대로 높인다. 최저 5%·최고 65%다. 안전한 대처·귀환은 이 강행 판정을 하지 않는다.
- 강행 생존 후 시험을 치르면 두 판정을 각각 보존한다. 후속 연도에 능력이나 생사가 바뀌어도 당시 판정 기록은 다시 계산하지 않는다. 모든 수치는 게임 규칙이며 역사적 확률이 아니다.
- 일반 선택은 즉시 변화만 보여 준다. 선택마다 임의의 성공·실패를 추가하지 않았다. 정치·일반 돌발 사건에는 이번의 능력 판정 카드가 아직 없다.
- 선택 직후 결과는 먼저 엔진에서 확정·저장한다. 화면은 1.4초의 종이·도장 연출 뒤 결과를 공개한다. 건너뛰기와 동작 줄이기를 지원하며, 다시 불러온 보고서는 정적으로 표시한다. 연출이 게임 시간이나 난수를 소비하지 않는다.
- 보고서의 선택적 `checks` 필드로 이전 저장과 호환한다. 새로운 위험도 규칙이므로 도전 규칙을 `family-20261113-2`로 올렸다. 이전 규칙 링크로 같은 결과를 약속하지 않는다.

검증: 동일 시드·서로 다른 능력에서 실제 강행 결과가 달라지는 사례, 판정 확률·요인 스냅샷, 재접속 재현, 잘못된 판정 인물 거부, 연출 중 결과 숨김, 건너뛰기 시 저장 불변, 복원 시 정적 결과를 확인한다.
