# 조선 생활사 서사 구현 범위

구현 기준일: 2026-11-03. 역사 근거는 `JOSEON-EXPANSION-SOURCES.md`에 정리한다. 다음은 역사적 사실의 추가 주장이 아니라 게임 구현 규칙이다.

- 여섯 경로는 준비 비용을 지불한 뒤 다음 선택에서 하나의 결과를 완수한다. 선택 한 번이나 높은 능력치만으로 성취를 지급하지 않는다.
- 각 경로의 두 결과는 각각 한 번만 완수할 수 있다. 완수에는 별도의 준비가 필요하며, 결과 ID와 연도·담당 인물을 보존한다.
- 준비는 후계자가 이어받을 수 있다. 완료 기록의 담당자는 당시 생존한 대표다.
- 보류하면 다른 선택 두 번 뒤에 돌아온다. 중단과 시대 만료는 성취가 아니며 준비 비용을 돌려주지 않는다.
- 일반 경로는 1392~1893년, 교역은 1500~1893년, 전란·재건은 1592~1660년에 열린다. 이 경계는 게임의 단순화다. 1592~1660년 전체가 전쟁 중이었다는 의미가 아니다.
- 실제 역사 사건과 유배·부채 대응은 서사보다 우선할 수 있다. 시대 경계를 넘긴 준비는 정리 사건으로 끝난다.

## 역사와 이야기의 구분

- 서책·문서는 사가의 자료다. 안의·손홍록 등의 실존 실록 보전 공적을 플레이어 가문에 부여하지 않는다.
- 일반 교육·의술은 1392년에도 가능하게 한다. 한글이나 1433년 편찬된 특정 의서를 그 이전부터 사용했다고 서술하지 않는다.
- 구휼 선택은 무상으로 곡식을 나누는 활동이다. 환곡 대여와 동일한 제도로 처리하지 않는다.
- 의술 전승은 돌봄과 지식 전달을 뜻한다. 완치·구명·실제 치료 효과를 보장하지 않으며 게임의 생활환경 점수는 의학적 측정값이 아니다.
- 1500년은 장시 교역 경로의 게임 개방선이다. 대동법·공인·신해통공을 모든 시대와 지역에 적용하지 않는다.
- 전란·피난·재건은 역사적 전란과 전후 사회를 배경으로 한 가상 가족 이야기다. 실제 전쟁의 승패를 결정한 공적으로 처리하지 않는다.
- 민원 결과는 가상 사건의 제한적인 조정이다. 역사적 민원 성공이나 요구의 전면 수용을 보장하지 않는다. 여성 대표도 문서·가족 문제에 참여할 수 있다.
- 가족 합의는 시대·지역별 상속 관행을 모두 같게 만들지 않는다. 이 서사는 기존의 게임상 균등 상속 알고리즘을 바꾸지 않는다.
- 수공업은 손기술·작업·전수를 다룬다. 근대식 특허·대량 공장·전면적인 자유 기업 제도를 과거에 투영하지 않는다.

## 저장과 결정성

`State.chronicles`는 선택 경로, 진행 중인 준비, 완료 ID 목록, 완료 이력으로 구성한다. 기존 저장에 필드가 없으면 비어 있는 기본값을 읽고, 복원이나 화면 표시에서 난수와 상태 변경을 일으키지 않는다. 완료 ID와 이력은 같은 순서로 한 번씩 추가하며 결말 판정은 이 결과를 사용한다. 전투·질병으로 사망했다는 별도 근거가 없으면 단절의 원인을 임의로 붙이지 않는다.
